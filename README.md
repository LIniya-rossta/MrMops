# Линия роста — white-label интернет-магазин

Продающее демо digital-студии и готовая основа для интернет-магазинов клиентов. В проекте есть адаптивный каталог, поиск, категории, конфигуратор стоимости, форма заявки и отправка выбранных решений в Telegram.

## Как адаптировать под новую компанию

Основные данные собраны в `store.config.ts`:

- название и подпись бренда;
- заголовок и описание;
- пакеты, модули, цены и категории;
- подходящие отрасли;
- этапы работы и FAQ.

Цвета и визуальный стиль находятся в начале `app/globals.css`. Для нового клиента достаточно обновить конфигурацию, палитру, метаданные и переменные Telegram.

## Архитектура

- GitHub Pages публикует статическую витрину из `docs/`.
- `worker/index.ts` проверяет выбранные услуги и отправляет заявку владельцу в Telegram.
- Telegram-токен и ID чата хранятся только на сервере в `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
- `app/page.tsx` используется и серверной версией, и статической Pages-сборкой.

## Локальный запуск

Требуются Node.js 22.13+ и pnpm 11.

```bash
pnpm install
cp .env.example .env.local
pnpm run dev
```

Откройте `http://localhost:3000/`.

## Проверка и публикация

```bash
pnpm run build
pnpm run build:pages
```

- `pnpm run build` проверяет серверную версию.
- `pnpm run build:pages` собирает статическую витрину в `docs/`.

GitHub Pages настроен на ветку `main` и папку `/docs`. После изменения проекта пересоберите `docs/`, зафиксируйте изменения и отправьте их в `main`.
