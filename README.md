# Лапа Маркет — white-label сайт для зоомагазинов

Готовая основа интернет-магазина зоотоваров, которую можно адаптировать под разные магазины. В проекте есть адаптивный каталог, поиск, категории для питомцев, корзина, доставка, оформление заказа и отправка заказа менеджеру в Telegram.

## Как адаптировать под новый зоомагазин

Основные данные находятся в `store.config.ts`:

- название, подпись, город и телефон;
- категории питомцев;
- товары, цены, объём упаковки и отметки;
- условия доставки, преимущества и FAQ.

Палитра и визуальный стиль задаются переменными в начале `app/globals.css`. Метаданные для поисковиков и социальных сетей находятся в `app/layout.tsx` и `github-pages/index.html`.

## Как работает заказ

- покупатель добавляет товары в корзину;
- выбирает доставку и оплату;
- указывает телефон и адрес;
- сервер проверяет товар и цену по каталогу;
- состав заказа, сумма и контакты приходят менеджеру в Telegram.

Токен Telegram-бота и ID чата хранятся только на сервере в `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.

## Локальный запуск

Требуются Node.js 22.13+ и pnpm 11.

```bash
pnpm install
cp .env.example .env.local
pnpm run dev
```

Откройте `http://localhost:3000/`.

## Сборка и публикация

```bash
pnpm run build
pnpm run build:pages
```

GitHub Pages публикует статическую витрину из `docs/`. Серверная версия принимает заказы по `/api/order` и отправляет их в Telegram.
